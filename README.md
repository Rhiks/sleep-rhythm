# 睡眠节律跟踪（本地应用）

纯静态文件，不联网、不上传。装到 iPhone 主屏幕后像普通 App 一样全屏打开，断网也能用。

## 晨间首页（2026-10-05 更新）

打开后先看最近一晚完整记录：明确的睡眠结论、实际时长、深睡百分比和分钟数、REM、已记录清醒。深睡比例以已分期睡眠为分母，同时显示分期覆盖；记录时间轴区分睡眠阶段和未记录空白。心率、HRV、呼吸、血氧与判断方法收在可展开的详情中。

日期选择器和近 7 个日历夜的小卡可以查看历史。昨夜没有完整数据时会明确提示，并注明展示记录的实际日期。**不足 3 小时按手表关机或记录中断片段跳过**，不纳入质量结论、均值和个人基线。记录原文保留，导出与恢复继续兼容旧备份。

深睡与个人基线的比较，采用当前夜之前 28 个日历日内、起止及总量一致、记录缺口不超过 30 分钟且不超过记录区间 10% 的夜晚；每项指标至少需要 5 晚有效值。深睡比较另外要求至少 80% 的睡眠有分期。页面显示实际样本数。近期对比采用最近 7 天与此前 28 天，缺失天不当作 0。

“睡得不错”等是本应用的透明提示，不是医学评分：首先检查记录是否完整，再综合睡眠时长、已记录清醒和记录连续性；深睡比例不参与好坏评级，睡得更久不会自动被扣分。“睡眠 / 记录起止区间”只称为记录区间睡眠占比，不冒充临床睡眠效率。用户可设置时长目标，并用“精神不错 / 一般 / 仍然困倦”保存每晚醒后的主观感受；再次点已选项可取消。

页面更新需一并部署 index.html、morning.css、sleep-insights.js、morning-view.js、sw.js、manifest 和图标。计算与交互验证命令：node --test tests/*.test.cjs。测试全部使用虚构记录，仓库不包含个人健康备份。

## 一、装到主屏幕（一次性，约 3 分钟）

iOS 只允许从 https 地址“添加到主屏幕”，所以需要把这个文件夹放到任意静态托管上。托管只负责把页面发给你的手机一次，健康数据不会经过它。

GitHub Pages 做法：

1. 新建一个仓库，把本文件夹里的 `index.html`、`sw.js`、`manifest.webmanifest`、三个 `icon-*.png` 传上去（不要传备份 json）。
2. 仓库 Settings → Pages → Branch 选 `main`、目录选 `/root`，保存，等一分钟。
3. iPhone 用 Safari 打开 `https://<用户名>.github.io/<仓库名>/`。
4. 点分享按钮 →“添加到主屏幕”。
5. 从主屏幕图标打开，页面底部“怎么更新数据、备份与恢复”→“恢复备份”，选 `sleep-backup-2026-10-05.json`。

之后都从主屏幕图标进。Safari 里的页面和主屏幕图标的数据是分开存的，以图标为准。

## 二、日常更新：快捷指令（不用再导出 115MB 的 zip）

在“快捷指令”App 里新建一个指令，取名“睡眠更新”，按顺序加这些操作：

1. **查找健康样本**：类型 是 睡眠；开始日期 在过去 5 天内；排序 开始日期，最早优先。
2. （可选，各加一个“查找健康样本”，筛选同上，只换类型）心率、呼吸频率、心率变异性、血氧饱和度、静息心率、日照时间。
3. **文本**：按下面的样子填。井号行照抄，方括号处插入对应那一步“查找健康样本”的结果变量，再点一下变量选属性：

```
#sleep
[睡眠样本 → 开始日期]
#sleep_end
[睡眠样本 → 结束日期]
#sleep_src
[睡眠样本 → 来源]
#sleep_val
[睡眠样本 → 值]
#hr
[心率样本 → 开始日期]
#hr_val
[心率样本 → 值]
#rr
[呼吸频率样本 → 开始日期]
#rr_val
[呼吸频率样本 → 值]
#hrv
[心率变异性样本 → 开始日期]
#hrv_val
[心率变异性样本 → 值]
#ox
[血氧样本 → 开始日期]
#ox_val
[血氧样本 → 值]
#rhr
[静息心率样本 → 开始日期]
#rhr_val
[静息心率样本 → 值]
#daylight
[日照样本 → 开始日期]
#daylight_val
[日照样本 → 值]
```

   每个日期变量都要把“日期格式”改成“自定”，格式串填 `yyyy-MM-dd HH:mm:ss`。只有 `#sleep` 那四段是必需的，其余没加就整段删掉。

4. **拷贝至剪贴板**（输入是上一步的文本）。想留文件就再加一个“存储文件”，存成 `sleep-feed.txt`，打开“覆盖”。

用法：早上运行一次指令 → 打开应用 → 点“从剪贴板更新”。也可以点“导入”选 `sleep-feed.txt`。

说明：这套文本格式在电脑上用你的真实数据模拟校验过，算出的结果和完整导出一致；但快捷指令本身没法在电脑上运行，第一次跑如果提示日期读不出来，多半是日期格式没改成自定。

## 三、完整更新

“健康”→ 头像 →“导出所有健康数据”→ 应用里点“导入”选 zip。步数、最长静坐、午后心率台阶只有这种方式才有，隔几周做一次即可。

## 四、备份

页面底部“导出备份”。清除 Safari 网站数据或删除主屏幕图标会清掉记录。
